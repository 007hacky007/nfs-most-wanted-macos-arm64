# Changelog

What each version of NFSMW Builder brings. The newest version is first.

## 1.1.0 - 2026-11-01

### Added
- The launcher tells you when a newer NFSMW Builder is out, with What's new, Download and Not now. It checks once a day, and turning off Check for updates stops all network requests.
- NFSMW Builder can update an existing NFSMW.app using the game inside it, so you do not need your discs again. You can also drop an NFSMW.app onto the Game copy row. The button reads Update NFSMW.app with the old and new version, and saves and settings are kept.

### Changed
- NFSMW.app now holds your whole game copy, including the other files from the discs or your installed folder. It needs no game folder and keeps working wherever you move it. Apps made by earlier Builders need your original game copy one more time.
- The launcher no longer has a game folder choice and always plays the game inside the app. If those files are missing or damaged, it says so and asks you to build the app again.
- Mac programs hidden in a game copy are left out of the app, and files from your game copy or disc images keep their download quarantine.
- Remove build files is now Delete temporary files, and Remove downloads is now Delete downloads. Both say what they delete and what they keep, and the finished build shows how much space was freed.

## 1.0.0 - 2026-10-31

### Added
- NFSMW Builder makes NFSMW.app on your Mac from your own copy of Need for Speed Most Wanted (2005), PC USA English Black Edition (4 CDs), given as an installed folder or the four disc images. It updates the game to v1.3 itself.
- A checklist that fixes each missing item with one button. No Terminal needed. Interrupted downloads continue where they stopped, and you can use a Most Wanted HQ file you already have.
- The game runs as native Apple Silicon code with Metal graphics and CoreAudio sound. No Wine, Rosetta or emulator.
- The original game: menus, profiles, Quick Race and the Career, with the original music, sound, videos and in-engine cutscenes.
- A launcher with resolutions in 4:3, 16:9, 16:10 and other sizes, plus three game modes: Standard, HQ visuals only, and Full HQ with the Most Wanted HQ 1.20.9 mod.
- WidescreenFix for proper widescreen resolution, HUD and movies.
- Keyboard and game controller support.
- A loading screen with a progress bar while graphics are prepared.
- Your saves are kept apart from the game files, with separate saves for each game mode.
